# Antójate

Tienda en línea del cliente Antójate, construida como app de Frappe sobre ERPNext v16.

- `antojate/api/` — endpoints públicos (checkout, webhook de pagos).
- `antojate/antojate/doctype/` — doctypes propios de la tienda.
- `antojate/www/` — páginas públicas del storefront.
- `antojate/templates/` — parciales Jinja reutilizables.

Para levantar el entorno completo, mirá `../../deploy/scripts/bootstrap.sh`.
